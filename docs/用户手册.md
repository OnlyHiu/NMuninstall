## 1. 安装与卸载应用

### 安装

双击下载的安装包：

- **NSIS**（`NMUninstall_1.0.0_x64-setup.exe`）：按向导完成，默认安装到「所有用户」目录
- **MSI**（`*.msi`）：可用于企业批量部署

安装程序会在检测到缺少 WebView2 Runtime 时自动下载安装（需要联网）。Win10 1809
的用户请先手动安装 [WebView2 Evergreen Bootstrapper](https://developer.microsoft.com/microsoft-edge/webview2/)。

### 卸载本工具

与普通程序一致：Windows「设置 → 应用 → 已安装的应用」→ 找到 **NMUninstall** → 卸载。

本工具的配置文件与日志保留在用户目录下，如需彻底清除可手动删除：

```
%APPDATA%\com.onlyhiu.nmuninstall\
%LOCALAPPDATA%\com.onlyhiu.nmuninstall\
```

## 3. 查找程序

### 搜索

在工具栏搜索框输入关键词，列表会实时过滤。搜索范围包括：

- 程序名称
- 发布者
- 版本号

多个关键词用空格分隔，需要**全部命中**（例如 `microsoft code` 只会同时含
「microsoft」和「code」的程序）。搜索框为空时显示全部。

按 `Esc` 可清空搜索框，`Ctrl` + `F` 快速聚焦。

### 排序

点击任意列标题切换排序：

| 列 | 说明 |
|----|------|
| 名称 | 默认升序 |
| 版本 | 按版本字符串排序 |
| 发布者 | 按名称排序 |
| 安装日期 | 按日期排序 |
| 大小 | 默认**降序**（最大的在前） |

缺失该字段的行（如没有发布者）**始终排在最后**，无论升序还是降序。

### 显示系统组件

默认隐藏 Windows 更新、Visual C++ 运行库等系统条目。勾选工具栏的
**「显示系统组件」**后，这些条目会出现在列表中，并带「系统组件」标记。

在设置中修改该选项会立即重新扫描。

## 4. 查看程序详情

- **单击**行：选中，右侧详情面板显示该程序
- **双击**行：同时打开详情面板
- **右键 → 查看详情**：效果相同

详情面板包含：图标、名称、版本、发布者、安装日期、占用大小、32/64 位标记、
注册表来源、安装位置、卸载命令原文、静默卸载命令原文、注册表键完整路径。

面板提供四个操作：

| 操作 | 说明 |
|------|------|
| 卸载 | 同右键菜单「卸载」 |
| 打开安装目录 | 在资源管理器中打开安装位置；程序未声明安装位置时该按钮禁用 |
| 复制卸载命令 | 把 `UninstallString` 复制到剪贴板 |
| 检测残留 | 手动检查该程序是否还有残留 |

## 5. 卸载程序

### 基本流程

1. 在列表中选中程序，右键选择 **卸载**（或按 `Delete`、点击详情面板的「卸载」）
2. 弹出确认框，显示程序名称、版本、发布者，以及**将要执行的命令**
3. 点击 **开始卸载**

### 关于「将要执行的命令」

确认框里显示的是**解析后**的可执行文件与参数，而不是注册表里的原始字符串。
例如注册表中记录：

```
"C:\Program Files\Vendor App\unins000.exe" /S
```

确认框会显示同样的内容；而 MSI 记录：

```
MsiExec.exe /I{0A1B2C3D-...}
```

确认框会显示为：

```
> msiexec.exe /X{0A1B2C3D-...} /norestart
```

（`/I` 安装开关被转换为 `/X` 卸载开关，并追加 `/norestart` 防止卸载后自动重启。）

如果程序声明了静默卸载命令，勾选「静默卸载」后确认框会切换为显示该命令。

### 结果提示

| 状态 | 含义 | 建议 |
|------|------|------|
| **卸载完成** | 卸载器已执行完毕并返回成功 | 无需操作 |
| **已启动卸载程序** | 卸载器有独立窗口，工具不会等待 | 在卸载器窗口中完成操作，然后点「刷新」 |
| **卸载失败** | 卸载器返回了非零退出码或启动失败 | 查看提示中的原因，常见为需要管理员权限 |

程序**不需要管理员权限**运行。若卸载器需要提权，会由卸载器自身弹出 UAC 提示。

### 没有卸载命令的程序

部分程序（尤其是便携版或只提供安装的功能包）在注册表中没有
`UninstallString`。这类程序仍会显示在列表中，但「卸载」按钮被禁用，
右键菜单里对应项也是灰的，鼠标悬停时说明原因。

### 系统组件

系统组件（Windows 更新、运行库等）默认隐藏。开启「显示系统组件」后可以看到它们，
但建议谨慎操作：卸载系统组件可能导致系统更新失败、Office 无法启动等后果。
本工具在确认框会对系统组件显示红色警告条。

## 6. 静默卸载

在卸载确认框中勾选 **「静默卸载（不显示界面）」**。

### 什么时候真正静默

| 情况 | 行为 |
|------|------|
| 程序在注册表声明了 `QuietUninstallString` | 使用该命令执行 |
| 程序是 MSI 安装（`WindowsInstaller = 1`） | 使用 `UninstallString` 并按需追加 `/qn` |
| 其他情况 | **回退为交互式卸载**，结果中会提示 |

### 为什么不自动猜静默参数

NSIS 用 `/S`、Inno Setup 用 `/VERYSILENT`、InstallShield 用 `/s` —— 各不相同，
而且**部分卸载器静默失败时依然返回成功**。如果工具自行猜测，结果会是
「显示卸载成功，但程序还在」，比报错更难排查。

因此本工具只信任程序自己声明的静默命令，以及 MSI 官方支持��� `/qn`。

如果勾选了静默但实际回退了，结果提示会明确说明。

## 7. 卸载残留与清理

### 自动检测

在 **设置 → 行为 → 卸载后检测残留** 中开启后，每次卸载结束会自动检测。
也可以随时对任意程序手动执行：右键 **「检测残留」** 或在详情面板点击同名按钮。

### 报告会列出什么

- **注册表项**：卸载后仍然存在的 `Uninstall` 子键
- **安装目录**：卸载后仍然存在且**包含文件**的安装目录（空目录不算残留）

报告会显示目录占用的空间与文件数量。

### 清理

1. 勾选要删除的条目，或点「全选可删除项」
2. 点击 **「删除所选」**
3. 再次确认 —— 确认框会**逐条列出**将被删除的路径

删除是不可撤销的，请仔细核对列表。

### 保护规则

出于安全考虑，部分条目**只允许查看，不允许删除**，会在报告里标注原因：

| 情况 | 原因 |
|------|------|
| 路径不在 `C:\Program Files`、`C:\Program Files (x86)`、`C:\ProgramData` 之内 | 超出允许删除的目录范围 |
| 路径包含 `Windows`、`Users`、`ProgramData` 等系统目录段 | 系统关键目录 |
| 路径是目录联接或符号链接 | 可能指向其他位置 |
| 目录位于用户数据目录（如 `AppData`） | 可能是你仍在使用的数据 |

被保护的条目仍可点「打开目录」自行查看和判断。

清理目录时，本工具只删除目录**内部**的文件和随之变空的子目录，**保留顶层目录本身**。

## 8. 设置

点击工具栏 **「设置」**（或按 `Alt` + `S`）。

### 外观

| 选项 | 可选值 | 说明 |
|------|--------|------|
| 主题 | 跟随系统 / 浅色 / 深色 | 「跟随系统」会随 Windows 的深色模式自动切换 |
| 界面语言 | 简体中文 / English (US) | 立即生效 |
| 列表密度 | 宽松 / 紧凑 | 紧凑模式行高更小，一屏可看到更多程序 |

### 行为

| 选项 | 默认 | 说明 |
|------|------|------|
| 显示系统组件 | 关闭 | 修改后立即重新扫描 |
| 显示 32 位程序 | 开启 | 关闭后隐藏 WOW6432Node 下的程序 |
| 卸载前二次确认 | 开启 | 关闭后点击「卸载」会直接执行（仍会显示命令预览的确认框） |
| 卸载后检测残留 | 关闭 | 见 §7 |
| 默认使用静默卸载 | 关闭 | 控制卸载确认框中「静默卸载」的初始勾选状态 |
| 卸载超时（秒） | 300 | 30–3600。仅对可等待的卸载器（MSI、rundll32）生效 |

### 关于

显示版本号、运行时信息、配置文件路径，并提供「打开日志目录」按钮。

设置修改后点「保存」立即生效并写入磁盘。配置文件采用原子写入，中途断电不会损坏；
如果文件本身已损坏，会被重命名为 `settings.json.corrupt` 保留，程序以默认设置启动。

## 9. 系统托盘

关闭窗口不会退出程序，NMUninstall 会继续在系统托盘运行。

- **单击托盘图标**：显示并聚焦主窗口
- **右键托盘图标**：
  - 显示主窗口
  - 重新扫描
  - 打开日志目录
  - 退出

要从托盘完全退出，请使用托盘菜单的「退出」。

## 11. 常见问题

**Q: 列表里找不到我刚装的程序**
A: 点「刷新」重新扫描。仍找不到则说明该程序不是通过标准安装器安装的（例如
MSIX/UWP 应用），本工具不扫描这类安装。

**Q: 某个重要程序不见了**
A: 它可能是系统组件，勾选「显示系统组件」查看。状态栏会显示被跳过的条目数量。

**Q: 卸载时提示「启动卸载程序失败」**
A: 注册表中记录的卸载器路径已不存在（程序文件被手动删除过）。这是程序自身的问题，
本工具无法修复。

**Q: 点卸载后程序还在**
A: 多数情况是卸载器弹出了独立窗口，需要你在那个窗口里点「卸载」。工具在无法
确定卸载器是否结束时只显示「已启动」而不会谎报成功。完成卸载后点「刷新」。

**Q: MSI 程序卸载时电脑想重启**
A: 工具会自动追加 `/norestart`，卸载结束后不会自动重启。

**Q: 卸载要管理员权限吗**
A: 本工具本身不需要。只有当卸载器要写入受保护位置时，会由卸载器自己弹 UAC。

**Q: 清理残留时有些条目是灰的**
A: 出于安全考虑，只有位于允许删除目录（`C:\Program Files*`、`C:\ProgramData`）内的
条目才能删除。可以点「打开目录」自行确认后手动处理。

**Q: 工具会联网吗**
A: 不会。本工具完全离线运行，唯一可能的网络访问是安装包在缺少 WebView2 时下载
WebView2 引导程序。

**Q: 如何反馈问题**
A: 请附上日志文件内容（设置 → 关于 → 打开日志目录），并提交到
<https://github.com/OnlyHiu/NMuninstall/issues>。
